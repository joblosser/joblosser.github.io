Driver的输出阻抗 ​

一、Datasheet 为什么不给输出阻抗 ​

一般的芯片手册不会给出驱动器的输出阻抗，这个值确实也没有办法明确给出来。

因为输出阻抗并不是确定的：外部负载不同，输出阻抗可能也不同；高电平输出阻抗和低电平输出阻抗，这两个值可能也不同。

知道了输出阻抗，就知道串联端接该加多大的电阻；加不同端接电阻的时候，高低电平的波形、过冲和下冲为什么不一样，也都跟驱动器的输出阻抗有关。

二、output buffer 的等效电路 ​

驱动器输出的 output buffer 等效电路里是两个 MOS 管，输出之后有 ESD 结构，还有 output buffer 的电容，后面这一块是封装的参数。

硅片上的信号要引出来。封装实际上是把硅片放到一块很小的 PCB 上，可能也是几层板，通过封装形式把信号引到这块小板上。

比如很老的那种打邦定线，把信号引出来打到 PCB 上；封装这块小的 PCB 再把信号引出来，通过打孔下来到BGA焊球。

封装上也会有走线，封装上 output buffer 接口那段引线的等效参数，用 RLC 代表封装的参数。

有人用封装的 L 和 C，用根号下 L 和 C 去算输出阻抗，实际上这样算不对。

芯片的输出阻抗，也就是相当于它的内阻，如果用package来代替的话，没法算晶体管级的，封装代表不了晶体管级的。

package这一块相当于 PCB 上信号进入芯片之后链路中间的一小段，用链路中间一小段的特性来代表Die上的特性，显然是不对的。

所以，芯片的输出阻抗不能从 IBIS 模型的 package 参数来算，因为驱动器的输出阻抗实际上是管子的特性，不是package的特性，是Die上面的MOS管的特性 。

三、MOS 管的工作区 ​

Datasheet上一般不会给出驱动器的输出阻抗，首先是因为直流情况和交流情况下，输出阻抗是不一样的；另外推拉输出结构的上下拉两个管子是 PMOS 和 NMOS，这两个管子的特性也不一样。输出阻抗和这两个管子的导通特性有关。

MOS 管的典型特性有可变电阻区、饱和区。

MOS 管的典型特性曲线：可变电阻区、饱和区、截止区，预夹断点轨迹，击穿区。

电路真正工作的时候，管子工作在可变电阻区；正常工作的时候，这个管子就类似于由栅源电压控制的一个可变电阻。

这是设计上有意让它在这个区域工作。

四、直流输出阻抗与交流输出阻抗 ​

稳态情况下的直流输出阻抗，和它带的负载有关，可以用管子的直流工作点、它的电压和电流算出来。

比如管子稳定地带着 50 Ω 负载，没有信号跳变：管子上会加载一定电压，也有一定电流流过通道，电流不会是无限的，这样管子就表现出一定的直流阻抗。

管子的工作特性我们知道，直流工作点可以通过直流负载线标出来；管子的工作特性曲线和直流负载线的交点，就是管子的直流工作点。直流工作点对应着一个电流、一个电压，这就是稳态情况下的直流输出阻抗。

如果在静态工作点附近来了某一个类似于噪声信号的交流信号，这个信号感受到的阻抗，是管子工作特性曲线在直流工作点这一点的切线，因为交流是它变化的那一部分。直流阻抗是这个电压除以电流，交流阻抗是这一点的切线斜率，两者不一样，芯片手册也就没有办法给出这个输出阻抗值。

输出阻抗和直流负载线有关，实际工作带的直流负载到底是多少并不确定：

典型情况下带的是 50 Ω 特性阻抗的传输线，真正工作的时候可能是 50 Ω，可能是 49 Ω，有的时候还会把阻抗控制在别的值。

直流负载不一样，这个值就没办法给出。

五、两种输出阻抗对信号的影响 ​

驱动器对两种信号表现出两种阻抗。

直流输出阻抗Zdc决定了稳态情况下驱动器加载在传输线上的电压幅度，也决定信号反射之后波形的宏观特征：

高电平稳态情况下最高幅度能达到多大、低电平稳态情况下能达到多少，都跟直流输出阻抗有关；

比如，用的是末端并联端接，上拉可能把低电平给抬起来，低电平被抬起来多高，也和管子低电平输出时的直流阻抗有关。

交流输出阻抗Zac决定了驱动器对反射噪声的吸收能力，只是影响信号波形上一些很小的细节。

信号波形总体的宏观特征，是由直流输出阻抗决定的。

大多数芯片的直流工作点电压比较低。

工作点电压比较低的时候，直流输出阻抗和交流输出阻抗差别很小，考虑信号波形宏观特性的时候，就可以直接用直流输出阻抗代替。

把宏观特征控制住之后，那些小的细节不必管；比如过冲、下冲最大能达到多少，用直流输出阻抗就能确定下来。

六、串联端接阻值的选择 ​

推拉输出结构的上下拉 MOS 管不是同一种，上下拉的输出阻抗可能不一样。

以 sn74lvc16245 芯片为例，低电平输出的时候直流输出阻抗大概是 10.6 Ω，高电平输出的时候直流输出阻抗大概是 21 Ω。

串联端接要求直流输出阻抗加上端接电阻 Rt 等于传输线的特性阻抗：

Zout+Rt=Z0

高低电平的输出阻抗不一样，理论上找不到一个输出高低电平时都完全匹配的阻值，只能去做一些平衡。

这个例子里，低电平输出的时候大概是 11 Ω，高电平输出的时候是 21 Ω。

按照高电平输出阻抗来匹配， 21 Ω的时候应该串联端接一个 29 Ω 的电阻；

高电平好了，低电平的下冲就比较大，低电平匹配就不好。

按照低电平输出阻抗来匹配， 11 Ω的时候应该串联端接一个 39 Ω 的电阻；

低电平好了，高电平这块就塌下来了，下冲减小了，上升沿这块又不是很理想。

七、负载变化与精确匹配 ​

驱动器的输出阻抗和它所带的负载有关，直流工作点决定了它的直流输出阻抗。

如果外接的负载变了，直流负载线变了，静态工作点、直流工作点也变了，直流输出阻抗就会发生变化。

也就是说，外面加了串联端接电阻之后，驱动器的直流工作点发生变化，它的输出阻抗又变了。

按低电平静态时 50 Ω 负载线算出来加 39 Ω，按理说应该是完好的匹配，现在还是有一段大约150mV的下冲，也没有完全匹配。

这种匹配是不可能精确匹配的，对于多数芯片来说都是这样，只要能做到波形能接受就可以了。

八、输出阻抗的估算方法 ​

正常工作的时候不会专门去评估驱动器的输出阻抗，一般都是直接通过仿真看波形：

加上多大的电阻之后波形是什么样子，能不能把波形搞得比较好、满足要求。

只有在 debug 的时候，想找原因、想把各个关节点都摸清楚，才需要了解它的输出阻抗特性。

评估输出阻抗要用到芯片的仿真模型。

IBIS 模型里有两个曲线，跟直流输出特性有关。

第一个是上拉曲线。芯片是推拉输出，上拉曲线描述的是上拉的时候，外面接的电压不同，上面这个管子的特性是什么样子。

上拉是指 output buffer 上拉：它输出高电平的时候，上面上拉的这个管子打开，给它加不同的电压差，它的电流是什么情况，这是它的直流特性。

这描述的是上拉的这个管子的特性；下拉曲线描述的则是下拉 MOS 管的特性。

IBIS 模型里就有这样的上拉曲线和下拉曲线两组数据。

如果要算上下拉情况下的阻抗特性，用这两个曲线就能算出来。

比如下拉曲线和 50 Ω 的直流负载线，两条线的交点就是推拉输出下拉时候管子的特性。

算出来的直流阻抗：低电平输出的时候是 10.6179 Ω。

同样用上拉曲线也能算出一个：

output buffer 输出高电平的时候，也就是上拉那个管子打开的时候，它的输出特性，直流阻抗 21 Ω。

通过这两个曲线，就能把它的特性算出来。

工程上想评估它，可以这样：

仿真工具很容易找。比如想评估高电平输出的时候输出阻抗是什么特性，就用 IBIS 模型的输出接一个 50 Ω 的电阻下拉——下拉相当于输出阻抗和 50 Ω 分压。测它输出的信号波形，稳态情况下高电平是多少。

这个测量得到的稳态量，是 VCC、50 Ω，还有输出阻抗分压得到的，这样就能算出高电平输出的时候这个阻抗是多少。

50Zdc_high+50VCC=VmeasZdc_high=50(VCCVmeas−1)

测低电平输出时的直流阻抗，可以把电阻上拉，上拉之后看低电平是多少，也用分压的关系算出来。

Zdc_lowZdc_low+50VCC=VmeasZdc_low=50VmeasVCC−Vmeas

通过几步仿真、简单的计算，就能比较粗略地估计出来。

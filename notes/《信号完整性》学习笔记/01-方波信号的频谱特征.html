方波信号的频谱特征 ​

一、信号完整性与电源完整性 ​

信号完整性的英文名称是 Signal Integrity，简称 SI；

还有一个所谓的 PI，是电源完整性。

实际上信号完整性是一个比较广义的概念，应该是包含电源完整性的。

只不过现在专业越分越细，电源完整性这一块渐渐地就被独立出来，实际上这两个方面是密不可分的。

信号完整性这个概念，文字上的定义五花八门。

理解信号完整性的概念时，没有必要去纠结这些文字。

先看一个信号传输的整个环境。

信号从驱动器出来时，可能带有它的时钟、有它本身的功能电源。

经过一个无源的通道，传输过程中还可能会受到电源分配系统、也就是所谓 PDN 的影响。

传输到接收端，接收端对于有些芯片来说，也会有它的参考时钟，还有它的电源。

这些东西都会影响信号。

发送端波形干净，经无源通道到接收端已畸变。

所以，最终结果可能导致信号发出来的时候质量比较好，到达接收端的时候波形扭曲得比较厉害，或者信号质量其他方面的指标恶化得比较厉害。

信号完整性无非就是这些众多的影响因素影响信号各方面的质量，包括波形、包括它的边沿。知道这是什么东西就可以了，没有必要去纠结文字上的表述。

二、周期信号可以分解成余弦波的叠加 ​

任何周期信号都可以写成这样一种形式：

x(t+nT)=x(t)n=0, ±1, ±2, ⋯

这个大的 T 指的是周期信号的周期。

周期的倒数，也就是该信号的基频，记为 f0，f0 等于 1/T。

对应基频的角频率是 ω0=2πf0=2πT。

从数学里面我们知道，任何周期信号都可以分解成一系列的正弦波、余弦波以及直流分量的叠加：

x(t)=a0+a1cos⁡(ω0t)+b1sin⁡(ω0t)+a2cos⁡(2ω0t)+b2sin⁡(2ω0t)+⋯+ancos⁡(nω0t)+bnsin⁡(nω0t)=a0+∑n=1∞[ancos⁡(nω0t)+bnsin⁡(nω0t)]

这个式子看起来比较麻烦，里面也看不出太多的东西来。

为了详细地分析这个信号里面到底包含了哪些成分，把它做一下变形。

实际上这两个系数 an、bn，可以利用这种三角的关系。

假如把 an、bn 作为一个三角形的两个直角边，那么斜边就是 an2+bn2。

用这种方式做一下简单的变形，an 除以斜边、bn 除以斜边，就相当于这种形式：

x(t)=a0+∑n=1∞[ancos⁡(nω0t)+bnsin⁡(nω0t)]=a0+∑n=1∞{an2+bn2[anan2+bn2cos⁡(nω0t)−−bnan2+bn2sin⁡(nω0t)]}

其中，

c0=a0cn=an2+bn2φn=arctan⁡(−bnan)

cn 是斜边，φn 是斜边与 an 的夹角。

x(t)=c0+∑n=1∞{cn[cos⁡(φn)cos⁡(nω0t)−sin⁡(φn)sin⁡(nω0t)]}=c0+∑n=1∞[cncos⁡(nω0t+φn)]

从这个式子能看出来，周期信号分成了一系列的余弦波。

对一个余弦波来说，它在频率上表现出来的是单个频点的一根谱线。

这个频谱的形状是什么样的，看一个方波信号，它的占空比是 1/4 的时候，它的谱线是一根一根的，每根谱线代表了一个余弦分量。

占空比 1/4：谱线一根一根，4f、8f、12f 处为零。

三、理想方波的频谱系数 ​

数字信号实际上都是由 0、1 构成的，表现在模拟域就是一个类似于方波的波形。

所以，为了分析数字信号里面包含哪些频率成分，从理想方波入手是一个比较好的切入点。

前面看到周期信号可以分解成一系列余弦波的叠加，那么这个系数到底是多少？

x(t)=c0+∑n=1∞[cncos⁡(nω0t+φn)]

如果这个理想方波信号它的占空比是 50%，这几个系数非常有特点。

占空比 D=τ/T=50%。

假如方波最大的幅度是 1，直流分量 c0 是 1/2。

奇次谐波，就是 1 次、3 次、5 次谐波，它们的系数是 2nπ：1 次谐波是 2π，3 次谐波是 23π。

对于偶次谐波，所有系数都是 0。

相位是一个固定的值，和频率没关系，是 −π2。

c0=12cn={2nπ,n=1,3,5,⋯0,n=2,4,6,⋯φn=−π2,n=1,3,5,⋯

理想方波有一个非常重要的特点，就是它的幅度跳变的过程中是不需要时间的，也就是说它的上升时间是零。

系数知道了之后，就可以把理想方波信号分解成一系列正弦波的叠加。

x(t)=12+2πcos⁡(ω0t−π2)+23πcos⁡(3ω0t−π2)+25πcos⁡(5ω0t−π2)+⋯=12+2πsin⁡(ω0t)+23πsin⁡(3ω0t)+25πsin⁡(5ω0t)+⋯

同样可以想象，在频谱上表现出来的是一系列离散的谱线。

这在信号处理里面是一个很基本的知识点，时域周期、频域离散，这是必然的规律。

占空比是 50% 的时候，它只包含奇次谐波。

可以用 MATLAB 简单地看一下，它到底是不是这么回事。

把占空比设成 0.5，一次谐波有幅度，二次谐波幅度是零，三次谐波又有幅度了。

对应的系数 cn，偶次谐波都是 0。

这就是所谓的幅度谱。

偶次谐波幅度全为 0，奇次谐波幅度按 2/(nπ) 递减。

四、正弦波叠加重构方波 ​

既然理想方波信号能分解成一系列正弦波的叠加，那就做一个实验看一下。

把这么多的正弦波按照 2π、23π、25π、⋯ 这样的系数叠加在一起，会不会出现方波信号的特征。

就是把这些东西一个一个地往上加，先加直流分量 1/2，方波信号的特征就出来了。

至于这些振荡，也就是所谓的吉布斯现象，不用管它，这是信号分解再合成之后必然产生的一种现象。

很明显有一个特点：

添加的频率分量比较少，比如加到 11 次谐波，有一点方波的特征了，但振荡还是比较厉害。

加到 11 次：有一点方波的特征了，振荡还是比较厉害。

添加的频率分量越多，方波的特征越明显。

加到 51 次：方波的特征更明显了。

加到 210 次，它会变得更陡。

加到 210 次：边沿更陡，几乎贴着理想方波。

这个也从另外一个角度验证了，理想方波信号确实能够分解成这样一系列正弦波的叠加。

从频谱的角度看，它里面包含很多很多的频率分量。

添加的越多，它越接近理想方波。

五、方波信号的频谱包络特征 ​

从前面几个波形看出来了，频谱有这样一种不断下降、不断振荡的趋势。

前面所看到的，是一根一根的谱线。

如果说把这些谱线都连起来，它的包络就是下面这种样子。

包络的数学表达式是：

C(f)=2τT|sin⁡(πfτ)πfτ|

其中 τ 要注意，是理想方波信号的脉宽，后面是一个 sin⁡xx 这样的形式的式子，这是它频谱的包络线。

包络线是 sin x / x 形式，越往高频幅度越低。

越往高频幅度越低，但用这个图还有一些主要特征看不太清，只知道越高频的幅度可能越小，也就是正弦波它的系数会越来越小。

换一个角度，把幅度和频率都用对数形式来表示，就能看出一种非常明显的特征。

对这个包络线公式两边同时取对数，乘积取对数后为相加：

20log10⁡C=20log10⁡(2τT)+20log10⁡|sin⁡(πfτ)πfτ|

左边是一个常数项，右边是一个变化的量。

当 πfτ 远小于 1 的时候，随着 f 趋向于 0，常数项是不变的，后面 sin⁡xx、x 趋向零的时候，它的极限是 1，也就是 20log10⁡1，这一项变成零了，极限值是前面那个常数项。

20log10⁡C=20log10⁡(2τT)+20log10⁡1=20log10⁡(2τT)

也就是说频率趋向于零的时候，包络有一条渐进线，是一条水平的直线，代表一个常数。

当 πfτ 远大于1的时候，随着 f 趋向于无穷大，常数项还是不变。后面这个 sin⁡xx，分子 sin⁡x 始终在±1之间摆动，而分母 x 一直在增大，所以商最大也就是 1x 那个大小，可以近似成这种形式。

20log10⁡C=20log10⁡(2τT)+20log10⁡(1πfτ)

在这个变化的部分，取两个点，这两个点是十倍频的关系。

两个频点幅度上的差别是多少？

比如 f2=10f1，两个式子相减：

[20log10⁡(2τT)+20log10⁡(1πf2τ)]−[20log10⁡(2τT)+20log10⁡(1πf1τ)]=20log10⁡(πf1τπf2τ)=20log10⁡(110)=−20 dB

这非常有规律：

两个频点如果是十倍频的关系，幅度上的差别就是 20 dB。

当频率趋向于无穷大的时候，会有一条倾斜的渐进线，斜率是每十倍频程 20 dB 的衰减。

低频水平、高频每十倍频程衰减 20 dB，交点在 1πτ。

最终它的频谱的两条渐进线：

趋向于零的时候是一个固定的值，频率趋向于无穷大的时候是一个倾斜的直线，斜率是每十倍频程 20 dB。

注意这两个渐近线的交点，这是非常关键的一个特征点。

两条渐近线相交，交点算出来是 1πτ，这个 τ 是方波信号的脉宽。

也就是说它的拐点和方波信号的脉宽有关，更进一步，是和它的占空比有关。

用 MATLAB 把包络线和渐近线都画出来，看它是不是有这个趋势。

把占空比设成 0.35，横轴和纵轴都取对数的时候，它的包络渐近线每十倍频程 20 dB 衰减，这个特征非常明显。

占空比 0.35，高频每十倍频程 20 dB 衰减，低频渐近线低于 0 dB。

频率趋向于零的时候，这条渐近线是小于 0 dB 的。

这是为什么？

频率趋向零的时候，这条水平的渐近线代表的是 2τ/T，而 2τ/T 又是什么？

占空比乘以二。

设占空比为 0.35，2×0.35=0.7，取对数后小于 0 dB；

占空比是1的话，2×1 取对数变成 0 dB；不到1就小于 0 dB。

占空比 0.25 同样是这个规律，低频渐近线小于 0 dB。

占空比 0.5 时，水平渐近线是 2×0.5=1，取对数等于 0 dB。

六、小结 ​

首先要理解数字信号的频谱，它到底有什么样的特点。

要想理解信号完整性里面的一些问题，信号的频谱是必须要了解的。

因为信号完整性实际上从频率上来说，就是因为信号里面的各个频率成分和其他的一些干扰因素相互作用，改变了波形的形状，或者改变了波形的一些参数特征。

从另外一个角度来说，方波信号能够分解成一系列正弦波的叠加，那么每一个正弦波实际上代表一个频谱的分量。

如果把这个频谱的分量，无论是它的幅度还是它的相位都改变了，再重新合成，在各项相加合成的时候，合成的就不是原来的信号，它就会导致这个信号波形的畸变。

然后周期信号可以分解成一系列正弦波的组合，也就是所谓的傅里叶分解，这个纯粹是数学上的东西。

理想方波可以分解成一系列正弦波的组合。

所谓理想方波，它的典型特征是它的状态跳变是不需要时间的，也就是说它的上升时间是零。

理想方波它的频谱包络有两条渐近线：

趋向于低频的时候是一条水平的渐近线，趋向于高频的时候是一条斜率为每十倍频程 20 dB 衰减的斜线。

它的拐点是 1πτ，这个 τ 指的是理想方波信号的脉宽。
